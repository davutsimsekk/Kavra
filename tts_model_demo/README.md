# Bağımsız TTS dinleme demosu

`venv\\Scripts\\python.exe tts_model_demo\\generate_demo.py` komutu, Anka'nın
mevcut değerlendirme referans sesini kullanarak üç metin için Coqui XTTS v2,
Anka TTS ve Chatterbox Multilingual WAV çıktıları üretir.

Ardından `tts_model_demo\\index.html` dosyasını tarayıcıda aç. Çıktılar
`tts_model_demo\\public` altına yazılır; ana Ders Stüdyosu arayüzüne bağlı değildir.
